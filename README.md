## 📌 Project Overview 
এটি একটি নিউজ পোর্টাল ওয়েব অ্যাপ, যেখানে ব্যবহারকারীরা ক্যাটাগরি অনুযায়ী বিভিন্ন নিউজ আর্টিকেল দেখতে পারে। সাইটটি Firebase-এ হোস্ট করা এবং রাউটিং ব্যবহার করে প্রতিটি ক্যাটাগরির নিউজ আলাদা পেজে দেখানোর ব্যবস্থা রয়েছে। UI টি ক্লিন, রেস্পনসিভ এবং ব্যবহারকারী সহজেই এক ক্যাটাগরি থেকে অন্য ক্যাটাগরিতে যেতে পারে।

## ✅ Main Technologies Used
1. React.js

Full frontend UI এবং component-based structure তৈরি করতে ব্যবহৃত।

2. React Router

Category-based পেজ (যেমন: /category/1) তৈরি করতে রাউটিং ব্যবহৃত।

3. Firebase Hosting

পুরো প্রজেক্টটি Firebase-এ ডিপ্লয় করা হয়েছে।

4. Tailwind CSS / Custom CSS

UI, layout, spacing এবং responsive design এর জন্য Tailwind ও CSS ব্যবহৃত।

5. JavaScript (ES6+)

Logic, state management এবং API ডেটা হ্যান্ডল করতে ব্যবহার করা হয়েছে।

## ✅ Main Features
1. Category-wise News Display

/category/1 এর মতো রাউটে গিয়ে নির্দিষ্ট ক্যাটাগরির নিউজ দেখা যায়।

2. Dynamic Routing 

প্রতিটি পেজ আলাদা URL অনুযায়ী লোড হয় এবং ডেটা dynamic ভাবে দেখানো হয়।

3. Clean & Responsive UI

মোবাইল, ট্যাব, ডেস্কটপ—সব স্ক্রিনে রেস্পনসিভভাবে কাজ করে।

4. Firebase Hosting

পুরো প্রজেক্ট Firebase Web Hosting-এ ডিপ্লয় করা, তাই লোডিং খুব দ্রুত।

5. Reusable Components

Card, Layout, Header, Navbar ইত্যাদি React কম্পোনেন্ট হিসেবে পুনঃব্যবহারযোগ্যভাবে তৈরি।
